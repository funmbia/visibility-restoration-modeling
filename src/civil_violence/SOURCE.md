## Summary
The Epstein Civil Violence model is based on Joshua Epstein’s simulation of how civil unrest grows and is suppressed. Citizen agents wander the grid randomly, and are endowed with individual risk aversion and hardship levels; there is also a universal regime legitimacy value. There are also Cop agents, who work on behalf of the regime. Cops arrest Citizens who are actively rebelling; Citizens decide whether to rebel based on their hardship and the regime legitimacy, and their perceived probability of arrest.

## How to Run
1. Install Mesa with recommended dependencies:   
```pip install “mesa[rec]”```   
or   
```pip install mesa[rec]```
on Windows 

2. Change into the directory, then run the example:  
```
cd src/civil_violence
solara run app.py
```

3. Open the displayed local URL in your browser.
