## How To Run
*this assumes pip is installed*


##### 0. (Optional) Create and activate a virtual environment
```
python -m venv .venv
source .venv/bin/activate
```
or ```.venv\Scripts\Activate.ps1``` for Windows 
##### 1. Install the software requirements
```
pip install -r requirements.txt
```

##### 2. To run the Mesa Civil Violence example from the home directory
```
solara run src/civil_violence/app.py
```
else if already in the ```civil_violence``` directory
```
solara run app.py
```

##### 3. To run the adpated DEL02 YouTube Visibility model from the home directory
```
python src/project_model/app.py
```
else if already in the ```project_model``` directory
```
python app.py
```
Outputted files are saved in the ```outputs``` directory


## Brief description of the YouTube Visibility project
**Phenomenon**:    
When a video is wrongfully taken down on YouTube, a creator can appeal and get it reinstated. However, the visibility of the video suffers because it has missed out on the presentation opportunities it might have received while it was down. This project examines how much visibility loss such a video suffers and if that can be compensated for with temporary visibility boosts after the video is reinstated. 

**Inquiry Question**:     
In a simulated platform based on YouTube, to what extent can visibility boosts granted after reinstatement compensate for the exposure opportunities lost during a video's removal?

**Conditions**:    
The project has 3 conditons (not 2)
- Reference: the condition where no videos are taken down
- Current: a video is taken down for some time and simply made available again after a successful appeal
- Alternative: proposed arrangement where a reinstated video gets a visibility boost to make up for lost exposure opportunities

For details on how the simulation was developed, how the computation is arranged, what parts of YouTube is represented, or output interpretation, refer to [DEL02.1 Report](docs/DEL02.1_Report.pdf).

**Output File Format**:     
Output files follow the naming pattern as required. However, since there are three conditions, files that begin with '```reference_xxx```' are from the reference condition. 

Also, files that compare all 3 results (e.g. a bar graph) begin with '```ALL_xxx```'

**Limitations**:    
There are no run-time limitations for this project.
